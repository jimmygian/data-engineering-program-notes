# Amazon S3

Here's a quick summary of AWS object storage terminology:
- A [bucket](https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingBucket.html) is a **container for objects** stored in Amazon S3.
- An object is a **file** AND any **metadata** that describes that file. It has a unique identifier (**UUID**), also known as the **object key**.
Object storage allows the storage of **any object**; you can store not only structured but also unstructured and semi-structured data. 

To upload your data to Amazon S3, you need first to create an **S3 bucket** in one of the **AWS Regions**.
